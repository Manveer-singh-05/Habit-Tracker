# Habit Tracker

A responsive local-first habit tracker built with Vue 3, Pinia, Chart.js, and browser LocalStorage.

## Features

- Create, edit, and delete habits
- Mark a habit as done once per day
- Track streaks from stored daily history
- View weekly and monthly completion charts
- Persist data after refresh with LocalStorage
- Responsive layout for mobile, tablet, and desktop

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
